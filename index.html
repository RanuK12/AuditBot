Quick Start — Compare Two Sites

curl -X POST https://auditbot.ranuk.dev/compare \
  -H "Content-Type: application/json" \
  -d '{"url_a": "https://site-a.com", "url_b": "https://site-b.com"}'

Single Site Audit

curl "https://auditbot.ranuk.dev/audit?url=https://example.com"

CLI

python3 auditbot.py analyze --url-a https://site-a.com --url-b https://site-b.com
python3 auditbot.py compare --domain mysite.com --competitors rival1.com,rival2.com
